# Linux System Information Monitor

## About the Project

This project is developed as part of my Operating Systems CCA. The main aim of this project is to collect and display important information about a Linux system in one place.

Linux provides system information through different files in the `/proc` filesystem. This project reads that information and displays details such as CPU usage, memory, uptime, system load and running processes through a simple web dashboard.

The dashboard also refreshes automatically every 2 seconds so that the information stays updated.

## Live Website

[Linux System Information Monitor](https://aaliyafirzain.pythonanywhere.com/)

## Features

- Displays operating system details.
- Shows processor information and CPU usage.
- Displays RAM and memory usage.
- Shows system uptime and load average.
- Lists currently running processes.
- Automatically updates the displayed information.
- Provides a simple and easy-to-use interface.
